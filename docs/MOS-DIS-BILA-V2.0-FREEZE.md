# MOS-DIS / BILA V2.0｜正式收口规范

**状态：FROZEN / 正式收口**  
**日期：2026-10-02**

## 1. 定位

MOS-DIS / BILA V2.0 是 MOS「Church Formation」实践层中的门徒形成系统。

它不是积分系统、课程打卡系统或属灵成长评分系统，而是以圣经为中心，把：

**主日 → 每日跟随 → 生活实践 → 关系 → 使命 → 回顾反馈**

连接起来的生命跟随工具。

核心目标：

> **能用、肯用、爱用、有用；但完成记录永远不等于属灵成熟。**

## 2. 正式内容结构

### 52周

- 52个周单元
- 4个年度阶段
- 每周一个主日主题
- 每周一个 BILA 周引导
- 每周固定一段核心经文
- 52 × 7 = **364个日单元**

### 四个阶段

1. **I 看见自己**
2. **II 重新连接**
3. **III 进入生活**
4. **IV 结出果子**

365日不混入52周结构。

如需要年度总结/差派，可作为独立的年度第365日，不改变52周×7日的母结构。

## 3. 每周七日形成路径

每周固定采用：

1. **看见**
2. **挖根**
3. **回经文**
4. **对照**
5. **行动**
6. **关系**
7. **回顾**

这七步不是新的属灵等级，而是帮助使用者从认识问题进入经文、实践、关系与回顾的认知/行动路径。

## 4. 每日内容结构

当前正式364D数据以以下字段为基础：

- day_id
- dow
- week
- stage
- eight_step
- season
- reference
- week_theme
- week_guide
- day_title
- core
- question
- choices
- option_a
- option_b
- option_c
- life_action
- relationship_mission

其中：

- question 用于自我辨识，不作为评分题。
- choices 是单选反思，不产生属灵分数。
- life_action 把认识转入真实生活。
- relationship_mission 把生命形成延伸到关系、服事与使命。
- reference 必须能够由本地和合本 Bible Engine 调取。

## 5. 神学与形成边界

MOS-DIS / BILA 不把：

- 完成天数
- 完成率
- 单选结果
- 使用次数
- 连续天数

等同于属灵成熟。

系统可以记录「完成」，但不能据此宣称「生命已经成熟」。

因此正式版本：

- **无属灵成长评分**
- **无排行榜**
- **无积分竞争**
- **无等级竞争**
- **无人与人比较**

## 6. 与 Church Formation 的关系

MOS-DIS / BILA 对应 Church Formation 中的：

- 基督与生命
- 门徒形成
- 教会共同体
- 事奉与实践
- 使命参与
- 下一代与传承

它承担的是「实践进入生命」这一段，而不是独立定义 Church Formation。

其基本闭环为：

**圣经 → 看见 → 认识 → 对照 → 行动 → 关系 → 回顾 → 再实践**

并最终进入 MOS 的总闭环：

**研究 → 判断 → 建造 → 实践 → 观察 → 反馈 → 再研究**

## 7. 52W 与364D的关系

正式母关系：

**MOS-52W = 年度母表**  
**MOS-364D = 每日执行表**

52W 决定：

- 周主题
- 周功能
- 主日主题
- BILA 周引导
- 核心经文

364D 将每周展开为七个连续日单元。

因此：

> **不得让364D脱离52W独立漂移。**

任何日内容修改，都必须检查：

**经文 → 周主题 → 周引导 → 七日递进 → 实践**

的一致性。

## 8. Bible Engine

正式系统保留本地和合本 Bible Engine。

其职责是：

- 按经文引用调取文本
- 支持中文经文简称
- 支持单段、多段及跨书卷引用
- 保持课程内容与经文数据库分离
- 不让每日内容直接硬编码成唯一经文来源

经文是规范，BILA 内容是形成性应用。

## 9. 进度与跨电脑

当前应用采用本地浏览器保存使用者进度。

正式支持：

**导出进度 → 换电脑 → 导入进度**

课程内容仍由仓库中的正式CSV提供。

这意味着：

- 内容与个人进度分离
- 换电脑不会要求重新建立全部内容
- 不需要为了跨电脑而把个人数据公开到网络

## 12. 正式结论

MOS-DIS / BILA V2.0 的核心不是「364天内容很多」，而是：

> **把一年365天的人生，重新放回圣经、基督、关系、实践与使命之中；但不把属灵生命简化成数据。**

因此 V2.0 的核心闭环确定为：

**圣经 → 看见 → 挖根 → 回经文 → 对照 → 行动 → 关系 → 回顾 → 再实践**

并与 MOS Church Formation 接轨：

**真理 → 信念 → 关系 → 实践 → 习惯 → 性情 → 共同体 → 传承**
