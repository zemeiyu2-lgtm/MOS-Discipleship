# MOS-DIS 跨计算机使用说明

## 当前架构

- 课程内容：由 GitHub 仓库中的 `mos-52w.csv`、`mos-364d.csv` 提供，所有电脑使用同一份内容源。
- 用户进度：默认保存在当前浏览器的 localStorage。
- 跨计算机同步：通过「设置 → 导出我的进度 / 导入进度」完成，不依赖某一台电脑的本地文件。
- 导出的进度文件：JSON，包含完成记录、回应选择、提醒设置和用户名称。
- 导入时：若当前设备已有完成记录，会先提示确认，再覆盖当前本地进度。

## 从电脑 A 转到电脑 B

1. 在电脑 A 打开 MOS-DIS。
2. 进入「我的 → 设置」。
3. 点击「导出我的进度」。
4. 将生成的 `MOS-DIS-进度-*.json` 文件带到电脑 B。
5. 在电脑 B 打开同一版本 MOS-DIS。
6. 进入「我的 → 设置 → 导入进度」。
7. 选择 JSON 文件。
8. 页面重新显示导入后的完成记录。

## 重要边界

跨计算机同步的是**个人使用进度**，不是把数据写回 GitHub 仓库。

因此：
- GitHub = 统一的程序与课程内容源；
- 浏览器 = 当前设备的本地进度存储；
- JSON = 设备之间的可携带进度包。

这种设计不需要服务器数据库，也不会把个人进度自动公开到 GitHub。

## 版本兼容

当前进度键为 `mos_state_v15`。程序仍兼容读取旧的 `v14 / v11 / v1` 进度，因此升级不会主动丢失已有本地记录。

## 验收标准

- [x] 新电脑从 GitHub 获取同一课程内容
- [x] 当前电脑可以导出个人进度
- [x] 另一台电脑可以导入个人进度
- [x] 导入前检测现有记录并提示覆盖
- [x] 导入后重新渲染完成数、本周进度、全年进度和个人信息
- [x] 不需要把个人进度提交到 GitHub
