# Sermon Production

> Sermon Engine × BILA V1.0 production instances. This document does not replace the Sermon Engine mother specification or the BILA mother specification.

## Production boundary
- Sermon Engine: faithful exegesis → Sunday core → response direction.
- BILA: receives the Sunday core and leads weekly following, not seven mini-sermons.
- Weekly formation path: **看见 → 挖根 → 回经文 → 对照 → 行动 → 关系 → 回顾**.
- Completion, check-in, answers, or usage are never spiritual scores or maturity rankings.

## W23｜拉撒路的复活

**经文：** 约11:1–44

**释经中心：** 耶稣面对拉撒路的死亡显明自己是复活和生命，并在父的旨意中行动。

**主日核心：** 信靠主不等于立刻看见结果；可以把真实绝望带到耶稣面前，相信祂掌权。

**生活回应：** 把一个最难以改变的处境具体带到主前祷告，并寻找忠心的一步。

### Sermon Engine → BILA
- Sunday Core：信靠主不等于立刻看见结果；可以把真实绝望带到耶稣面前，相信祂掌权。
- BILA主题：把绝望带到主前，祂必指引你的路
- 七日形成：看见 → 挖根 → 回经文 → 对照 → 行动 → 关系 → 回顾
